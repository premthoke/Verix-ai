How It Works

From Upload to
Blockchain Proof

A seamless pipeline that takes any image through AI analysis, cryptographic hashing, and blockchain storage.

01

Upload Image

Drag & drop or select an image file. Multer handles secure memory-based file processing.

02

AI Analysis

Sightengine API analyzes the image for deepfake indicators and returns a Real/Fake verdict with confidence.

03

Generate Hash

A unique SHA-256 cryptographic hash is generated from the file contents — your digital fingerprint.

04

Store on Blockchain

The hash and AI result are permanently stored on an Ethereum smart contract via storeMedia().

05

Get Results & Report

View the detection result, download a PDF verification report with QR code, or verify later anytime.

Blockchain

Smart Contract
Interface

The Solidity smart contract that powers on-chain media verification.

MediaVerifier.sol 
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.0;

contract MediaVerifier {
    struct Media {
        string  hash;
        string  result;
        uint256 timestamp;
        bool    exists;
    }

    mapping(string => Media) public records;

    // Store media analysis on-chain
    function storeMedia(
        string memory _hash,
        string memory _result
    ) public {
        records[_hash] = Media(_hash, _result, block.timestamp, true);
    }

    // Verify media authenticity
    function verifyMedia(
        string memory _hash
    ) public view returns (bool, string memory, uint256) {
        Media memory m = records[_hash];
        return (m.exists, m.result, m.timestamp);
    }
}
